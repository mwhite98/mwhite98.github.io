Girlboss Lorem Ipsum

The prompt for this project was to generate a note using python, and insert that note into any website using the browser's dev console.

The website I chose to share my note in is the Government of Canada's unemployment insurance application webpage. For the note, I created a dictionary of words sourced from a number of girlboss motivational quote pages on Instagram. I implemented a simple syntax tree using python, and used this script to generate the content for the updated webpage. I re-styled the webpage using CSS.

Bork

Bork is a new, exciting, state-of-the-art, surge-pricing-subscription-based content management system for dogs that can communicate with buttons. It was built in response to the prompt to build a website based on one of Ian Mcdonald's ideas for a website.

The prompt I selected was to build "A website that is whole only if it contains its exact opposite; a counter-website". My idea was to make a "good" and "evil" version of the same website (i.e. a website that contains its shadow website). This quickly skewed so that the axis for "good" and "evil" in this scenario was "conversion", or the likelihood for the website to convert a visitor to a consumer. The "good" version of the website is one that follows UX standards, with ample calls to action, and the "evil" version of the website is one that could care less about conversion. As the user interacts with the good website, it triggers action in the evil website, as they are two parts of a whole.
